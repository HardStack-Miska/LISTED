## Текущее состояние приложения

### Реализованные функции:
- **Экраны:** Сегодня, Задачи, Календарь, Ещё (настройки)
- **Задачи:** создание, редактирование, удаление, завершение
- **Приоритеты:** P1 (красный), P2 (оранжевый), P3 (синий), P4 (без цвета)
- **Даты:** выбор даты, быстрые опции (сегодня, завтра, след. неделя)
- **Проекты:** группировка задач по проектам с цветами
- **Метки:** теги для задач
- **Подзадачи:** вложенные задачи
- **Календарь:** месячный вид с индикаторами задач
- **Поиск:** фильтрация по тексту
- **Сортировка:** по дате, приоритету, имени
- **Просроченные:** визуальная пометка красным
- **Тема:** светлая/тёмная
