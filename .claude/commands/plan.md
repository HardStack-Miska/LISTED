# /plan - Планирование фичи

Запусти субагент `planner` для детального планирования фичи.

## Инструкции

1. Проанализируй текущую структуру проекта
2. Изучи существующий код, связанный с фичей
3. Разбей фичу на конкретные задачи
4. Оцени сложность каждой задачи (S/M/L/XL)
5. Определи зависимости между задачами
6. Учти оффлайн-режим и синхронизацию

## Формат вывода

```markdown
## Фича: [название]

### Описание
[Краткое описание что делает фича]

### Задачи

- [ ] **[S]** Задача 1
- [ ] **[M]** Задача 2 (зависит от: Задача 1)
- [ ] **[L]** Задача 3

### Затрагиваемые файлы
- `src/...`

### Риски и вопросы
- ...
```

## Аргумент

$ARGUMENTS - описание фичи для планирования
