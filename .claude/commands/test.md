# /test - Запуск тестов

Запускает тесты и анализирует результаты.

## Команды

```bash
# Все тесты
npm test

# С coverage
npm test -- --coverage

# Конкретный файл
npm test -- path/to/file.test.ts

# Watch mode
npm test -- --watch
```

## Структура тестов

```
__tests__/
├── components/     # Тесты компонентов
├── database/       # Тесты WatermelonDB
├── stores/         # Тесты Zustand stores
├── hooks/          # Тесты кастомных хуков
└── utils/          # Тесты утилит
```

## Правила тестирования

### Обязательно тестировать
- Логика базы данных (CRUD операции)
- Синхронизация данных
- Кастомные хуки
- Утилиты и хелперы

### Можно пропустить
- Простые UI компоненты без логики
- Стили
- Константы

## При падении тестов

1. Прочитай сообщение об ошибке
2. Найди тест который упал
3. Проверь ожидаемое vs полученное
4. Исправь код или тест
5. Перезапусти тесты
