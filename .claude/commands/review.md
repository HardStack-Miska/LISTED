# /review - Code Review

Запусти проверку качества кода для текущих изменений.

## Что проверять

### TypeScript
- [ ] Нет `any` типов
- [ ] Strict mode совместимость
- [ ] Корректные типы для props и state

### React Native
- [ ] Функциональные компоненты с хуками
- [ ] StyleSheet вместо inline styles
- [ ] Правильное использование memo/useCallback/useMemo
- [ ] Корректная работа с FlatList/FlashList

### WatermelonDB
- [ ] Правильные декораторы (@field, @relation, etc.)
- [ ] Корректные запросы без N+1
- [ ] Обработка ошибок БД

### Общее
- [ ] Нет console.log
- [ ] Нет хардкода строк
- [ ] Понятные имена переменных
- [ ] Файлы < 300 строк
- [ ] Функции < 50 строк

## Формат вывода

```markdown
## Code Review Report

### Критические проблемы 🔴
- файл:строка - описание

### Предупреждения 🟡  
- файл:строка - описание

### Рекомендации 🟢
- файл:строка - описание

### Итого
✅ Готово к коммиту / ❌ Требуются исправления
```
