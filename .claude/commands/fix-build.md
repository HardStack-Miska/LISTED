# /fix-build - Исправление ошибок сборки

Анализирует и исправляет ошибки сборки проекта.

## Процесс

1. Запусти `npx expo export` или `npm run build` для получения ошибок
2. Проанализируй вывод ошибок
3. Найди корневую причину
4. Исправь проблему
5. Проверь что сборка проходит

## Типичные проблемы

### TypeScript ошибки
- Несовместимые типы
- Отсутствующие импорты
- Неправильные generic параметры

### Metro bundler
- Циклические зависимости
- Отсутствующие модули
- Проблемы с разрешением путей

### Native модули
- Несовместимость версий
- Отсутствующие нативные зависимости
- Проблемы с linking

## Команды для диагностики

```bash
# TypeScript проверка
npx tsc --noEmit

# Metro bundler
npx expo export --platform ios --dev
npx expo export --platform android --dev

# Очистка кэша
npx expo start --clear
```
