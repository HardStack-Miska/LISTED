# Sprint 4: Уникальные функции LISTED

## Концепция: "Task-First Notes"

LISTED объединяет лучшее из Notion (блочный редактор, вложенные страницы) и Todoist (управление задачами), но с уникальным подходом: **задачи живут внутри заметок**.

---

## Уникальные функции Sprint 4

### 1. Inline Tasks (Задачи в контексте)
**Отличие от конкурентов:** В Notion checkbox - просто галочка. В Todoist задачи отдельно от контекста. В LISTED - задачи с приоритетами и датами прямо в тексте.

```
Заметка: "Подготовка к презентации"

[ ] Собрать данные по продажам @today P1
    - Связаться с отделом аналитики
    - Экспортировать отчёт

Текст заметки продолжается...

[ ] Сделать слайды @tomorrow P2
```

**Реализация:**
- Новый тип блока `TaskBlock` с полным функционалом задачи
- Задачи из заметок автоматически появляются в Today/Upcoming
- Связь задача ↔ контекст (можно перейти к заметке)

### 2. Smart Links (Умные ссылки)
**Отличие:** Bidirectional links как в Roam/Obsidian, но проще.

- `[[Название страницы]]` - создаёт ссылку и backlink
- Автоматический граф связей между страницами
- Раздел "Linked mentions" на каждой странице

### 3. Quick Capture с AI-категоризацией (локальный ML)
**Отличие:** Быстрый захват мыслей с автоматическим определением типа.

- Ввод текста → автоопределение: это задача, заметка или идея?
- Автоматическое назначение приоритета по ключевым словам
- "срочно", "важно", "ASAP" → P1
- Дата в тексте → автоматический dueDate

### 4. Focus Mode (Режим фокуса)
**Отличие от Todoist:** Не просто список задач, а полноценный рабочий режим.

- Показывает одну задачу в полный экран
- Таймер Pomodoro встроен
- Контекст задачи (связанная заметка) доступен свайпом
- Статистика фокуса за день/неделю

### 5. Templates (Шаблоны страниц)
**Как в Notion, но локально:**

- Daily Note template с датой и структурой
- Meeting Notes с участниками и action items
- Project template со статусами и задачами
- Пользовательские шаблоны

### 6. Kanban View для задач
**Отличие:** Kanban не по статусам, а по приоритетам или датам.

- Вид: По приоритету (P1 | P2 | P3 | P4)
- Вид: По времени (Просрочено | Сегодня | Завтра | Позже)
- Drag & drop для изменения

## Технические требования

### База данных
- Добавить поле `sourcePageId` в tasks (связь с заметкой)
- Создать таблицу `page_links` для backlinks
- Добавить таблицу `templates`

### Новые компоненты
- `TaskBlock.tsx` - задача как блок в редакторе
- `BacklinksSection.tsx` - раздел связанных страниц
- `FocusMode.tsx` - экран фокуса
- `KanbanBoard.tsx` - канбан-доска
- `TemplateSelector.tsx` - выбор шаблона

### Изменения в существующих
- `BlockRenderer.tsx` - добавить TaskBlock
- `DatabaseService.ts` - методы для links и templates
- `(tabs)/_layout.tsx` - возможно новый таб Focus
